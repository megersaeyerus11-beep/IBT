# Addis Eats

A simple Ethiopian food ordering application built with React and Vite.

## Features

- React components and JSX
- Props
- useState
- useEffect
- useRef
- useMemo
- useCallback concepts
- Custom hooks
- API fetching
- Loading and error states
- React Router
- URL category filtering
- Dish detail pages
- Cart Context
- Cart persistence with localStorage
- Authentication Context
- Protected checkout
- Controlled checkout form
- Form validation
- Accessible form errors
- Error Boundary
- Lazy-loaded pages
- Responsive design
