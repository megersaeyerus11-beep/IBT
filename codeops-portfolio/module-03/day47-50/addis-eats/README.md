# Addis Eats

## Purpose
Addis Eats is a food ordering web application
built with Next.js and React.

Users can browse Ethiopian dishes, view dish
details, manage their cart, and place orders.

## Technologies
- Next.js
- React
- JavaScript
- Node.js
- Database
